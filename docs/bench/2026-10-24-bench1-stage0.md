## Observations

- The check was run halfway through B0, after the upload. The user: the
  board was uploaded once, the monitor was started (run 1), then restarted
  with a reset (run 2), with no reflash in between. The upload builds from
  the current `platformio.ini` (strong-symbol line commented), so the ELF
  checked is the default build that ran in runs 1 and 2. (The later 8-lane
  build of B1d has since replaced it in `.pio/build`.)
- Node id `FFCB`. Run 1's ready line was missed because the monitor opened
  after the board had booted; run 2 reset the board with the monitor open.
- Run 2: the second `?` was taken "not exactly 60 s, but close" after the
  first (74 s by `uptime_s`). Log file:
  `logs/device-monitor-261024-232457.log` on the bench PC.
- Run 2 printed an ESP-IDF error before the ready line:
  `E (1157) MSPI Timing: Failed to allocate dummy cacheline for PSRAM memory barrier!`
